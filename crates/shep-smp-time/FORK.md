# Monoio timer adaptation

Adapted from `monoio/src/time/` and `monoio/src/utils/linked_list.rs` in
[Monoio](https://github.com/bytedance/monoio/tree/8675e9406ea7943c441d969e38c3f5fc198ef6d1/monoio/src),
commit `8675e9406ea7943c441d969e38c3f5fc198ef6d1`, from the local checkout
in `~/monoio` (package version 0.2.4). This extraction uses the MIT license;
copies of Monoio's license and the Tokio attribution are included.

The wheel, sleep/timeout/interval futures, and list algorithms originate in
Monoio. The six-level, 64-slot hierarchy, millisecond rounding, lazy registration
and deadline extension, timeout polling order, and interval missed-tick policies
are retained. The unused upstream `wheel/stack.rs` is not copied. Entries and
links now use a timer-owned indexed slab instead of borrowed intrusive pointers.

Changes for Shep:

- Replace Monoio's `TimeDriver<D>` with a concrete local Timer. There is no
  driver trait, wrapped I/O backend, submit/park delegation, or runtime loop.
  The reactor owns the executor, timers, and io_uring operations and waiting.
- Expose `Timer::new(now)`, `with_capacity(now, capacity)`, `capacity()`, `with`,
  `advance(now)`, and `next_wake()`. The reactor supplies the epoch and current
  monotonic time. No clock trait or mock waiting backend is necessary.
- Store entries in `shep-util-slab`, with an initial reservation of 1,024 slots
  by default. Unpolled sleeps occupy no slots; first poll or reset registers
  one, retained until consumer Drop even after expiration. The slab grows as
  needed and retains capacity. A local Rc handle keeps state alive for consumers.
- Replace non-owning handles and next/previous pointers with private nonzero
  encoded slab IDs. Link mutations use checked access and sequential borrows.
  Readiness uses an explicit registered/pending/elapsed enum; entry fields need
  no individual Cell/RefCell wrappers, state sentinels, or stored completion
  result. No active timer errors were generated by this component before this
  change either; public error types remain available.
- Enforce `#![forbid(unsafe_code)]`. Delete raw-pointer handles, the generic
  unsafe Link trait/conversion hooks, unchecked indexing, and the outer entry
  UnsafeCell. Preserve Sleep's pin-shaped API and !Unpin marker for compatibility;
  the wheel itself no longer relies on future addresses or pinning. Interval
  boxing is unchanged.
- Release the timer-state borrow before cloning, dropping, or invoking wakers.
  Clone callbacks can expire a timer or cancel/register siblings and grow the
  slab. Polling reacquires the borrow and rechecks readiness before installation.
  Drop unlinks/removes a slot before destroying its entry outside the borrow,
  including a waker retained by a ready poll. This preserves the reentrant and
  panicking-waker safety fixes made during the earlier intrusive implementation.
- Consume popped IDs and finish entry transitions before invoking user callbacks.
  A live Sleep keeps its slot, and cancellation unlinks all membership before
  reuse. These private IDs therefore need no generation field under this
  protocol. Retaining IDs beyond ownership or in deferred batches would require
  revisiting that decision.
- `next_wake()` reports an absolute processing time, which may precede the user
  deadline when a coarse bucket cascades. Compute it on demand; clamp backward
  advancement to the wheel's current elapsed tick.
- Search the top level starting after the current slot. Entries in that slot
  belong to the next rotation; considering it first could hide earlier deadlines
  in other slots. Boundary/model tests caught this inherited upstream bug.
- Promote time to the crate root and keep internals private. Use standard
  `ready!`/`poll_fn`. `pin-project-lite` and `shep-util-slab` are the normal
  dependencies; the latter has no normal dependencies or unsafe source.
- Flatten the source into sibling modules under `src/`. Keep the scoped handle
  with the owner in `timer.rs`, and the ID list with its private entry links in
  `entry.rs`. `wheel.rs`, `level.rs`, and `sleep.rs` import their dependencies
  directly, with no nested forwarding modules. `Instant::now` calls the standard
  clock directly instead of passing through an obsolete clock-variant module.
- Use a scoped local handle through `Timer::with`, restoring the previous handle
  on return/unwind. Sleeps remain bound to their creation owner.
- Preserve the upstream wheel unit tests and adapt the four original list
  scenarios to slab-owned entries/IDs. New tests live in integration targets.
  Port Monoio's runtime timer smoke and connect-timeout drop checks to manual
  advancement and local futures. Existing tests cover rounding, resets,
  cancellation, wheel boundaries/rotations, missed ticks, and executor composition.
- Add capacity-boundary/reuse and completed-entry retention tests, plus custom
  clone callbacks that expire timers, grow/reuse slots, or panic. The raw waker
  fixture requires one documented unsafe construction in the integration-test
  crate; the library, examples, and benchmarks forbid unsafe code. Miri runs
  small pools for the large capacity test; native tests exercise full boundaries.
- Adapt examples/documentation to the standalone API; retain workspace formatting
  and the wheel's nested-if control flow.

Behavior retained for subsequent changes:

- A pending timer retains its first registered waker until it fires; polling
  from another task does not replace that registration.
- There is no active shutdown. Outstanding sleeps retain their state but cannot
  advance once the public owner is gone. Drop consumers before the owner.

See ARENA.md for ownership details and benches/README.md for before/after timing
and retained-memory measurements. This crate does not change the existing
`shep-smp` runtime or add io_uring operations.
